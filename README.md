# Flay · 국기 맞추기

Flay는 포켓몬 플레이와 비슷한 구성의 한국어 국기 퀴즈입니다. GitHub 저장소는 [himinseop/flay](https://github.com/himinseop/flay)입니다. `flag` 디렉토리에서 독립적으로 실행합니다.

- **타임어택**: 60초 동안 4개의 나라 이름 중 정답을 선택합니다. 정답 100점, 연속 정답 보너스는 10점씩 늘어나 최대 100점입니다. 시간은 왼쪽, 점수는 오른쪽에 표시하며 문제 전환 때 선택·정답·오답·마우스 강조를 초기화합니다. 키보드 1–4도 지원합니다.
- **마스터 도전**: 시간 제한 없이 10문제를 풉니다. 한글 이름은 글자마다 한 칸씩 입력하고, 하나의 실제 입력 요소를 문제 사이에 유지해 한글 조합과 키보드를 보존합니다. 틀리면 맞은 글자는 초록색, 틀린 글자는 빨간색으로 표시합니다. 입력을 고치면 다시 확인할 수 있으며 다음문제를 누르면 오답으로 기록하고 넘어갑니다. “패스”는 정답을 글자 칸에 채우며, 정답·패스 후에도 자동으로 넘어가지 않습니다. 별칭·영문도 같은 글자 칸에 입력하며 길이에 맞춰 칸이 늘어납니다. 한국/대한민국, 터키/튀르키예 같은 기존 별칭과 영문 이름도 인정합니다. 확인·다음문제 버튼은 글자 칸 바로 뒤에 배치합니다. 한글 조합 중 Enter는 제출하지 않습니다.
- **보너스·힌트**: 국기가 준비된 뒤 20초 동안 줄어드는 게이지에 따라 마스터 정답에 최대 50/100/150점 보너스를 더합니다. 10점씩 줄어들며 끝나도 계속 풀 수 있습니다. 한 글자 힌트는 문제마다 한 번만 사용하고 쉬움·보통은 첫 글자, 어려움은 임의의 한 글자를 채웁니다. 힌트를 쓰면 보너스는 사라지고 기본 점수는 절반이 됩니다. 보너스가 끝나면 힌트 버튼이 안내합니다. 시작 화면의 게임 안내에서 점수와 진행 방법을 확인할 수 있습니다.
- **난이도**: 쉬움은 친숙한 30개 나라, 보통은 전체 195개 나라, 어려움은 나머지 165개 나라를 출제합니다. 모든 난이도의 객관식 보기는 정답과 같은 대륙의 이웃 나라를 우선 사용한 뒤 같은 대륙의 다른 나라로 채웁니다. 쉬움의 출제 대상만으로 네 보기가 부족하면 같은 대륙의 전체 나라에서 채웁니다. 국기는 원래 색과 비율로 표시하며 실제 깃발 가장자리에 얇은 테두리를 넣습니다.
- **랭킹**: 모드 탭과 난이도 버튼으로 TOP 20을 선택합니다. 정상 완료와 그만하기 모두 0점보다 높은 순위권 점수를 등록할 수 있습니다. 1~3위는 메달, 동점은 최근 기록 우선, 날짜는 한국 시간 기준 오늘 HH:mm / 일·주·개월·년 전으로 표시합니다. 강조된 내 행에 이름을 입력하며, 빈 이름은 랜덤 나라 이름으로 저장합니다. 첫 방문에는 1~12글자의 탐험가 이름을 입력받고, 다음 방문에는 기억한 이름으로 바로 시작합니다. 시작 화면에서 이름을 바꿀 수 있고 랭킹에 자동으로 채웁니다. 다시 도전은 입력한 이름을 저장한 뒤 같은 모드·난이도의 시작 화면으로 돌아갑니다. 저장 실패 시 입력 화면과 이름을 유지합니다. 기존 기록은 그대로 보존하고 기록은 이 브라우저의 `flag-play-records`, 이름은 `flag-play-explorer-name`에 저장합니다. 공동 온라인 랭킹·초대 검증·공유 링크 관리·접속 기록은 포함하지 않습니다.
- **나라 도감**: 한글/영문/별칭/나라 코드 검색과 6개 대륙 필터를 제공합니다. 나라별 국기·정식 이름·현지 이름·수도/행정 중심지·언어·세부 지역·면적·연도별 인구·통화·국제 전화·인터넷 도메인을 볼 수 있습니다. 세계지도에 나라 영역과 대표 위치를 표시하며, 작은 나라와 섬은 점으로 표시합니다. 육지 국경을 맞댄 이웃 나라를 누르면 해당 도감으로 이동합니다. 위키백과 한국어/영어, 세계은행 인구 통계, OpenStreetMap 상세 지도 링크를 제공합니다. 위키백과는 해당 제목이 있으면 문서로 이동하고, 없으면 검색 결과를 보여줍니다. 수도와 현지 이름은 원문 표기, 언어와 통화는 브라우저가 지원하는 한국어 표기를 사용합니다.
- 첫 국기의 이미지 로딩과 디코딩이 완료된 후 게임과 타이머를 시작합니다. 다음 세 문제를 미리 준비하고 이미지 요소를 재사용합니다. 점수와 타임바는 국기 아래에 표시하며 문제 전환 때 타임바를 유지합니다.
- 배경은 국경이 보이는 연한 회색 로빈슨도법 세계지도입니다. 화면의 세로 높이에 맞춰 비율을 유지하고 중앙에 정렬합니다. [Justinkunimune의 Wikimedia Commons 지도](https://commons.wikimedia.org/wiki/File:Blank_world_map_Robinson_projection.svg)를 회색 육지와 국경선으로 조정한 로컬 SVG로 제공하며 CC0 1.0으로 사용할 수 있습니다. 출처와 라이선스는 푸터와 `MAP-LICENSE.txt`에 표시합니다.
- 버튼과 비입력 영역의 포커스는 해제하고 텍스트 입력의 포커스는 유지합니다. 국기 주변 점선과 상단 문제 종류 문구는 제거하고 국기 이미지 자체에 얇은 회색 보더를 표시합니다.
- 게임 중에는 메뉴·소개·푸터를 숨겨 국기와 답에 집중합니다. 모바일 마스터 도전은 보이는 화면 높이에 맞춰 고정하고, 키보드가 열려도 입력칸·확인/다음문제·패스·점수를 표시합니다. 정답 판정은 Flay의 글자 효과로 표시하며 포켓몬 이미지나 판정 이미지를 사용하지 않습니다.

| 마스터 난이도 | 기본 점수 | 최대 시간 보너스 | 힌트 사용 후 정답 |
| --- | ---: | ---: | ---: |
| 쉬움 | 100점 | 50점 | 50점 |
| 보통 | 200점 | 100점 | 100점 |
| 어려움 | 300점 | 150점 | 150점 |

## 실행

빌드나 외부 API 키가 필요 없는 정적 사이트입니다.

```sh
cd /Volumes/2012020601/Dev/lab/pokemon/flag
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
```

브라우저에서 <http://127.0.0.1:4174/>를 엽니다. `dist` 폴더를 정적 웹 호스팅에 그대로 업로드할 수 있습니다. 웹 서버는 필요하지만 게임 중 외부 국기 서버나 나라 API에 의존하지 않습니다.

## 데이터 및 출처

- 나라 범위: UN 회원국 193개와 비회원 옵서버 2개(바티칸/교황청, 팔레스타인). 영토·속령은 포함하지 않습니다. [UN 회원국](https://www.un.org/en/about-us/member-states), [비회원 옵서버](https://www.un.org/en/node/123012).
- 나라 정보: [mledoze/countries](https://github.com/mledoze/countries), [ODbL-1.0](dist/COUNTRIES-LICENSE.txt). 이 프로젝트의 `dist/countries.json` 파생 데이터베이스도 ODbL-1.0으로 제공합니다. UI/게임 코드는 이 데이터 라이선스와 구분됩니다. 원본의 바티칸 회원국 표기는 UN 자료에 따라 옵서버로 정정해 집계했습니다.
- 인구: [세계은행 SP.POP.TOTL](https://data.worldbank.org/indicator/SP.POP.TOTL), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). 2020~2026년 조회 결과에서 나라별 가장 최근의 값과 기준 연도를 저장합니다. 2026-10-02 수집본은 194개 나라의 자료를 포함하며 바티칸은 자료 없음으로 표시합니다. 인구는 수집 시점의 통계이며 실시간 추정치가 아닙니다. 각 도감에 출처·라이선스·해당 나라 통계 링크를 표시합니다.
- 지도: [Natural Earth 1:110m Admin 0](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/), [퍼블릭 도메인](https://www.naturalearthdata.com/about/terms-of-use/). 로컬 `dist/assets/world-map.svg`와 나라별 경로를 사용하므로 지도 표시에도 외부 API나 키가 필요 없습니다. 위치 점은 원본 나라 좌표로 수도 위치와 다를 수 있습니다. 작은 나라의 영역은 축척상 생략될 수 있으며 국경은 간략화된 원본을 따릅니다. 상세 지도는 OpenStreetMap에서 새 탭으로 열립니다.
- 국기: [Flagpedia / Flagcdn](https://flagcdn.com/). 원본 국기는 Wikimedia Commons 벡터 자료에 기반합니다. 각 이미지의 URL을 `countries.json`의 `imageSource`에 기록했습니다.
- 도미니카연방의 한글 이름은 [외교부 국가 정보](https://www.mofat.go.kr/www/nation/m_3458/view.do?seq=49)에 맞춰 원본 번역 오류를 보정했습니다. 도미니카공화국과 구분하여 정답을 처리합니다.
- 수집 날짜와 전체 개수는 `dist/countries-manifest.json`에 기록합니다. 수도·언어·대륙은 수집 시점의 데이터이며 실시간 정보가 아닙니다. 대륙은 원본의 region/subregion 분류를 사용합니다.

`python3 scripts/import-countries.py`로 자료와 PNG 국기를 다시 수집할 수 있습니다. 게임에는 195개 국기를 모두 로컬 파일로 포함합니다.

## 검증

```sh
npm install
npm test
```

테스트는 첫 이미지 준비·타이머·미리 불러오기, 난이도별 보기, 문제 전환 초기화, 주관식 별칭·영문·한글 조합, 보너스 시작·소멸·중복 점수 방지, 한 글자 힌트·절반 점수·다음 문제 초기화, 글자별 오답 재시도·패스·수동 다음 문제, 입력 요소·포커스 보존, 완료/그만하기 랭킹·이름 저장·실패 후 재시도·동점/날짜 처리, 기존 도감·지도·자료 링크를 확인합니다.

GitHub의 `main` push와 PR에서도 `.github/workflows/ci.yml`이 문법·데이터·게임·배포 설정을 검사합니다. `main`의 검증이 통과하면 [flay.pir.kr](https://flay.pir.kr/)에 자동 배포합니다. 자세한 AWS 구성과 복구 절차는 [AWS 배포 안내](docs/aws-deployment.md)를 참고하세요.
